# EvoRail Codex Plugin

This repo-local plugin connects Codex to the EvoRail MCP server and provides implementation guidance based on the authoritative EvoRail specifications.

Build the MCP package first:

```powershell
npm run mcp:build
```

Set `EVORAIL_MCP_BASE_URL`, `EVORAIL_MCP_TOKEN`, and `EVORAIL_MCP_PROJECT_ID` before using the server.
